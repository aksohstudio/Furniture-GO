# 1. Purpose

Sprint 08 develops the Cutting List Workspace.

The Cutting List Workspace automatically converts approved Furniture Objects into production-ready cutting information.

The workspace is responsible for:

- Cutting List Generation
- Board Layout Visualization
- Material Statistics
- Waste Analysis
- Production Reports

Board optimization is performed automatically by the Cutting Optimization Engine.

The Cutting List Workspace is responsible for displaying, reviewing, printing and exporting cutting information.

Complete the Cutting List Workspace required by Version 1.

The completed workspace shall support:

# 13. Design Principles

Sprint 08 follows these principles:

1. Simple First

2. Automatically Generated

3. Production-Oriented

4. Read-Only Production Data

5. Offline First

6. High Performance

7. PRD First

8. UI First

The Cutting List Workspace is responsible for displaying and exporting cutting information generated by the Cutting Optimization Engine.

Users review production information but do not manually edit calculated cutting results.
