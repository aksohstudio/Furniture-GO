# 1. Purpose

Sprint 06 develops the Furniture 3D Workspace.

The Furniture 3D Workspace is the real-time visualization environment of Furniture GO.

The workspace is responsible for:

- Real-time 3D Visualization
- Furniture Inspection
- Material Preview
- Production Verification
- Installation Preview

The 3D Workspace is responsible for visualization only.

It shall not perform production calculations.

---

# 2. Sprint Goal

Complete the Furniture 3D Workspace required by Version 1.

The completed workspace shall support:

- Real-time Rendering
- Camera Navigation
- Material Preview
- Transparency
- Section View
- Exploded View
- Production Mode
- Live Synchronization
