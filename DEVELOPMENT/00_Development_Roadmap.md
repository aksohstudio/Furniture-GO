# 1. Purpose

This document defines the official development roadmap for Furniture GO Version 1.

It specifies the implementation sequence, development phases, milestones, sprint planning, and product delivery strategy.

This roadmap serves as the primary reference for the implementation of the Furniture GO system.

All development shall follow the approved PRD and UI specifications.

---

# 2. Development Goal

Furniture GO Version 1 aims to deliver a complete offline furniture production system.

The objective is to transform furniture design into production-ready information through an integrated engineering workflow.

Version 1 includes:

- Project Management
- Project Recognition Workspace
- CAD Workspace
- Furniture Object Editor
- 3D Workspace
- Production Drawing
- Cutting List
- Purchase List
- Project Settings

Version 1 is designed as a fully offline system.

Internet connectivity is not required.

---

# 3. Development Principles

Furniture GO development follows these principles.

---

## PRD First

No development may begin before the corresponding PRD has been approved.

---

## UI First

Every implemented feature shall have an approved UI specification before development begins.

---

## Prototype Before Development

Major user interfaces should be reviewed through prototypes before implementation.

The purpose is to minimize redesign during development.

---

## Offline First

Version 1 shall operate completely without Internet connectivity.

Cloud services belong to future versions.

---

## Modular Architecture

Each major system shall be developed independently.

Modules communicate through clearly defined interfaces.

---

## Stable Before Expansion

Core production workflow shall be completed before advanced features are introduced.

---

## One Source of Truth

Furniture Objects are the single source of engineering data.

All connected modules synchronize automatically through the Furniture Object Engine.

# 7. Sprint Completion Requirements

A Sprint is considered complete only when:

- Development is completed.
- Internal testing has passed.
- Major bugs have been resolved.
- Related PRDs have been implemented.
- Related UI specifications have been implemented.
- Prototype matches the approved UI.
- Product Owner approval has been obtained.
