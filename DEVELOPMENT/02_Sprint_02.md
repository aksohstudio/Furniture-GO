# 1. Purpose

Sprint 02 establishes the Project System of Furniture GO Version 1.

The Project System becomes the foundation for every engineering workflow.

This Sprint focuses on creating, opening, saving, organizing and managing Projects.

Project storage and local databases are implemented as part of the Project System.

No production workflow shall be implemented during this Sprint.

---

# 2. Sprint Goal

Complete the Project System required by all future modules.

The completed system shall support:

- Project Creation
- Project Management
- Project Storage
- Local Database
- Official Databases
- Furniture Object Storage

The Project System shall become the foundation of Version 1.
