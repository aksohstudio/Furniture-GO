# 1. Purpose

The Production Drawing Workspace generates, reviews and manages manufacturing drawings for furniture production.

It converts approved Furniture Objects into standardized production drawings.

Production drawings are intended for:

- Factory Production
- CNC Preparation
- Assembly
- Installation

The workspace is responsible for reviewing and printing production drawings.

It is not intended for CAD editing.

---

# 2. Target Users

Furniture GO supports two primary user roles.

## Designer

Responsible for:

- Review Production Drawings
- Verify Design Intent
- Confirm Production Output

---

## Factory

Responsible for:

- Production Review
- Manufacturing
- CNC Preparation
- Assembly
- Installation
- Printing Production Documents

Production Drawings are generated automatically.

Users review, inspect and print drawings rather than edit them.

---

# 3. Design Philosophy

The Production Drawing Workspace focuses on manufacturing efficiency.

The interface shall provide:

- Clear Production Drawings
- Easy Verification
- Fast Printing
- Standardized Output
- Production Readiness Confirmation

The workspace shall minimize unnecessary editing functions.

Production drawings are manufacturing documents.

# 6. Production Drawing Preview

The center workspace displays generated production drawings.

Supported drawing types include:

- General Assembly
- Elevation
- Plan
- Section
- Door Drawing
- Drawer Drawing
- Panel Drawing
- Hardware Layout
- Hole Position Drawing
- Exploded Drawing (Future)

Supported functions include:

- Zoom
- Pan
- Page Navigation
- Print Preview

Production Drawings are read-only.

# 11. Door Processing Drawings

When required, the system automatically generates dedicated Door Processing Drawings.

Examples include:

- Hinge Hole Position
- Handle Position
- Decorative Groove Layout
- Glass Opening
- Door Swing Direction

---

# 12. Hardware Layout

Displays installation positions for:

- Hinges
- Drawer Slides
- Handles
- Lift Systems
- Leg Supports
- Connectors
- Accessories

Hardware information is generated automatically from the Furniture Object Engine and Official Hardware Database.

---

# 13. Revision Management

Each Production Drawing maintains revision history.

Examples:

- Revision A
- Revision B
- Revision C

Previous revisions remain archived.

Only the latest approved revision shall be used for production.

The Production Drawing Workspace shall generate and display drawings efficiently.

Large Projects shall remain responsive.
