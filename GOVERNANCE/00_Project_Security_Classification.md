# 1. Purpose

This document defines the official security classification policy for the Furniture GO project.

Its purpose is to protect the intellectual property, engineering knowledge, commercial information, source code, and documentation of Furniture GO.

Every project document, source file, database, and resource shall be classified according to the security levels defined in this document.

This document is the official security policy for the Furniture GO project.

---

# 2. Objectives

The security classification system is designed to:

- Protect intellectual property.
- Protect engineering knowledge.
- Protect commercial information.
- Protect source code.
- Control document distribution.
- Define access permissions.
- Support long-term project management.

---

# 3. Security Principles

Furniture GO follows these security principles.

• Least Privilege

Users shall only access information required for their role.

---

• Need to Know

Access shall be granted only when necessary.

---

• Single Source of Truth

Official documents shall always remain under Product Owner control.

---

• Controlled Distribution

Confidential information shall never be distributed without authorization.

---

• Offline First

Project security shall not depend on cloud services.

---

# 4. Security Levels

Furniture GO defines five security levels.

---

## Level S

### Founder Secret

Highest security level.

Accessible only by the Founder / Product Owner.

Contains the most sensitive business information.

Examples include:

- Commercial Strategy
- Pricing Strategy
- License System
- Anti-Piracy Design
- Future Product Roadmap
- Business Negotiations
- Investment Documents
- AI Core Algorithms
- Recognition Algorithms
- Formula Algorithms

Distribution is strictly prohibited.

---

## Level A

### Strictly Confidential

Accessible only by authorized core development members.

Examples include:

- Formula Engine
- Recognition Engine
- Internal Architecture
- Security System
- Internal APIs
- Engineering Rules
- Internal Technical Documents

External distribution is prohibited.

---

## Level B

### Internal Development

Accessible by the official development team.

Examples include:

- PRD Documents
- UI Documents
- Sprint Documents
- Source Code
- Internal Databases
- Development Documents
- Testing Documents

These documents shall not be publicly distributed.

---

## Level C

### Partner Access

Accessible only to authorized partners under appropriate agreements.

Examples include:

- Demo Versions
- SDK
- API Documentation
- Integration Guides
- Training Materials

Commercial redistribution is prohibited.

---

## Level D

### Public

Publicly available information.

Examples include:

- Official Website
- Product Introduction
- User Manual
- Release Notes
- Marketing Materials
- Feature Lists
- Tutorials

These materials may be distributed publicly.

# 7. External Developer Policy

External developers may:

✓ Develop software.

✓ Fix bugs.

✓ Implement approved features.

✓ Access assigned project files.

External developers shall not:

✗ Copy Furniture GO architecture.

✗ Copy project databases.

✗ Reuse Furniture GO source code for other projects.

✗ Redistribute confidential documents.

✗ Create competing products using Furniture GO assets.

---

# 8. AI Development Policy

AI development tools may be used to assist software development.

Examples include:

- ChatGPT
- GitHub Copilot
- Cursor
- Windsurf
- Claude

The following rules apply.

Allowed:

✓ Code generation.

✓ Documentation assistance.

✓ Refactoring.

✓ Debugging.

✓ UI implementation assistance.

Not Allowed:

✗ Upload complete confidential source code to public services.

✗ Upload confidential databases.

✗ Upload Level S documents.

✗ Upload Formula Engine algorithms.

✗ Upload Recognition Engine algorithms.

All AI-generated content shall be reviewed before inclusion in the official project.

---

# 9. Distribution Rules

Documents shall only be distributed according to their classification.

Level S

Distribution prohibited.

Level A

Authorized personnel only.

Level B

Internal development team only.

Level C

Authorized partners only.

Level D

Public distribution permitted.

---

# 10. Intellectual Property

All Furniture GO documents, databases, source code, engineering knowledge, UI designs, PRDs, development documents, and related materials remain the intellectual property of the Product Owner unless otherwise specified by written agreement.

Unauthorized copying, redistribution, modification, or commercial use is prohibited.

---

# 11. Compliance

All project participants shall comply with this security classification policy.

Failure to comply may result in removal of project access or other actions determined by the Product Owner.
