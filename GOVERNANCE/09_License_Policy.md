# 1. Purpose

This document defines the official licensing policy for the Furniture GO project.

Its purpose is to establish the ownership, licensing, distribution rights, and usage permissions of Furniture GO software, documentation, databases, and related intellectual property.

All participants shall comply with this policy.

---

# 2. Objectives

The License Policy is designed to:

- Protect intellectual property.
- Define ownership.
- Define usage rights.
- Control commercial distribution.
- Prevent unauthorized copying.
- Protect long-term commercial value.

---

# 3. Ownership

Furniture GO and all associated assets are the intellectual property of the Product Owner unless otherwise specified by a written agreement.

Project assets include, but are not limited to:

- Source Code
- PRD Documents
- UI Specifications
- Sprint Documents
- Governance Documents
- Databases
- Formula Engine
- Recognition Engine
- CAD Engine
- 3D Engine
- Graphics
- Icons
- Documentation
- Brand Assets

Ownership remains with the Product Owner.

---

# 4. Founder License

The Founder of Furniture GO retains a permanent license to use all official versions of the software.

This includes:

✓ Existing Features

✓ Future Features

✓ Product Upgrades

✓ Commercial Editions

✓ Subscription Features

✓ Internal Development Versions

unless otherwise specified by a separate written agreement.

The Founder License is perpetual and cannot be revoked without a mutually agreed written legal agreement.

---

# 5. Internal Development License

Authorized internal developers may:

✓ Access assigned project files.

✓ Develop approved features.

✓ Fix bugs.

✓ Improve performance.

✓ Participate in testing.

Internal developers may not:

✗ Claim ownership.

✗ Redistribute project assets.

✗ Commercialize Furniture GO independently.

✗ Remove ownership notices.

---

# 6. External Development License

External developers may be granted limited development rights.

External developers may:

✓ Implement assigned features.

✓ Resolve approved issues.

✓ Participate in testing.

✓ Access approved project resources.

External developers shall not:

✗ Copy project architecture.

✗ Reuse source code for unrelated commercial projects.

✗ Redistribute confidential documents.

✗ Create competing products using Furniture GO assets.

✗ Claim ownership of Furniture GO.

Access permissions shall follow the Project Security Classification policy.

---

# 7. Partner License

Authorized partners may receive limited rights under a written agreement.

Partners may:

✓ Demonstrate approved software.

✓ Evaluate the system.

✓ Perform agreed integrations.

✓ Provide technical support within the agreed scope.

Partners may not:

✗ Modify ownership.

✗ Redistribute protected assets.

✗ Reverse engineer proprietary systems.

✗ Transfer licenses without authorization.

---

# 8. Customer License

Customers receive a license to use Furniture GO according to the purchased edition.

Unless otherwise stated, customers may:

✓ Install the software.

✓ Use official features.

✓ Receive updates according to their license.

Customers may not:

✗ Reverse engineer the software.

✗ Redistribute the software.

✗ Remove copyright notices.

✗ Sell unauthorized copies.

---

# 9. Intellectual Property

The following remain protected intellectual property.

- Source Code
- Product Architecture
- PRD Documents
- UI Specifications
- Official Databases
- Formula Algorithms
- Recognition Algorithms
- CAD Generation Technology
- 3D Generation Technology
- Documentation
- Logos
- Branding

Unauthorized copying or commercial use is prohibited.

---

# 10. Open Source Components

Furniture GO may incorporate approved open-source software where appropriate.

Open-source components shall:

- Comply with their respective licenses.
- Be documented.
- Not affect ownership of proprietary Furniture GO assets.

Third-party licenses shall be respected at all times.

---

# 11. Commercial Distribution

Only authorized parties may distribute official versions of Furniture GO.

Commercial distribution requires approval from the Product Owner.

Unauthorized commercial distribution is prohibited.

---

# 12. License Violations

Examples of violations include:

- Unauthorized copying.
- Unauthorized redistribution.
- Reverse engineering.
- Commercial misuse.
- Removal of copyright notices.
- Unauthorized disclosure of confidential assets.

Violations may result in:

- License termination.
- Removal of project access.
- Legal action where applicable.

---

Future versions of Furniture GO may introduce additional licensing models.

Examples include:

These licensing models shall not affect ownership of the project.
