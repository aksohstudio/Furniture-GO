# 1. Vision

Furniture GO is a Production Intelligence Platform built for the furniture industry.

It is designed to understand designer drawings, construction environments, factory production rules and furniture manufacturing logic before generating production documents.

Furniture GO does not simply calculate.

Furniture GO understands first.

Then calculates.

---

# 2. Mission

To transform traditional furniture production into an intelligent digital workflow.

Furniture GO assists furniture professionals from the moment they receive a designer's project until every production document is generated automatically.

The goal is to reduce manual calculation, minimize production mistakes and preserve valuable production knowledge.

---

# 3. Product Goal

Furniture GO is not only a furniture calculation software.

Furniture GO is an intelligent production assistant.

The system analyzes the entire project before generating:

- Material List
- Cutting List
- Hardware List
- Quotation
- Production CAD
- Optional 3D Model

Every output is generated from production knowledge rather than manual calculation.

---

# 4. Core Workflow

Furniture GO follows the real workflow used by furniture professionals.

```text
Receive Original PDF

↓

AI Review

↓

Review Report

↓

Backup PDF Editing

↓

Site Measurement

↓

Discussion & Confirmation

↓

Lock Backup PDF

↓

Project Database

↓

Automatic Calculation

↓

Production Documents
```

The system understands the project before calculation begins.

---

# 5. Product Philosophy

Furniture GO does not replace experienced furniture professionals.

Furniture GO captures their knowledge.

The system converts years of production experience into reusable production rules.

Professional judgement always belongs to the user.

---

# 6. Core Value

Furniture GO creates value by combining:

- Project Intelligence
- Factory Knowledge
- Production Rules
- Cabinet Intelligence
- Automatic Calculation

The system becomes more valuable as its production knowledge continues to grow.

---

# 7. Long-term Vision

Furniture GO aims to become the industry's Production Intelligence Platform.

Instead of simply drawing furniture,

the system understands projects,

understands production,

understands factory standards,

and assists users in making better production decisions.

Future technologies such as AI will enhance this intelligence,

but the core production logic remains independent and reliable.

---

# 8. Product Principles

Furniture GO follows these principles across every module.

---

## 8.1 Understand Before Calculate

Furniture GO understands the project before performing any calculation.

The system analyzes:

- Designer Intent
- Cabinet Structure
- Construction Logic
- Factory Rules

before generating production documents.

---

## 8.2 Single Source of Truth

All production documents shall be generated from one confirmed project source.

The Locked Backup PDF becomes the only production reference after project confirmation.

The Original PDF shall always remain unchanged.

---

## 8.3 AI Assists, Humans Decide

Artificial Intelligence assists users by:

- Detecting problems
- Finding inconsistencies
- Identifying missing information
- Providing recommendations

Artificial Intelligence shall never automatically:

- Modify dimensions
- Change construction methods
- Approve production
- Replace professional judgement

Final decisions always belong to the user.

---

## 8.4 Review Before Production

Furniture GO shall never generate production documents immediately after importing drawings.

Every project shall first enter the Review Stage.

Users review:

- Drawing Issues
- Site Conditions
- Dimension Corrections
- Construction Notes

before locking the project.

---

## 8.5 Offline First

Furniture GO is designed to work completely offline.

Internet connection is never required for normal production work.

Cloud services are optional future extensions.

Offline capability shall always remain the primary design philosophy.

---

## 8.6 User Data Ownership

Project data belongs to the user.

Furniture GO shall never:

- Automatically delete projects
- Lock user data
- Remove user ownership
- Prevent users from accessing their own projects

Users always own their production data.

---

## 8.7 Fast • Convenient • Accurate

Every feature developed for Furniture GO shall prioritize:

- Fast
- Convenient
- Accurate
- Reliable

Complexity shall never reduce production efficiency.

---

# 9. Product Identity

Furniture GO is not a CAD software.

Furniture GO is not a PDF reader.

Furniture GO is not only a quotation software.

Furniture GO is a Furniture Production Intelligence System.

Its purpose is to bridge the gap between designer drawings and factory production.
