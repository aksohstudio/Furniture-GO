# 1. Overview

The User Workflow defines the standard working process followed by furniture professionals when using Furniture GO.

The workflow follows the real production preparation process, from receiving designer documents to generating complete production documents.

Furniture GO assists users throughout the workflow while preserving professional decision-making.

Users remain responsible for all engineering and production decisions.

---

# 2. Objectives

The User Workflow shall:

- Guide users through every project.
- Reduce manual preparation work.
- Assist project verification.
- Support site survey.
- Support project confirmation.
- Prepare production-ready information.
- Generate production documents.
- Preserve complete project history.

The User Workflow shall remain consistent for every project.

---

# 3. Standard Workflow

Every Project shall follow the same workflow.

Receive Designer Documents

↓

Import into Furniture GO

↓

AI Scan

↓

Review Recognition Report

↓

Site Survey

↓

Update Editable Project PDF

↓

Discuss with Designer / Owner

↓

Confirm Project

↓

Generate Production Documents

↓

Review Production Results

↓

Export / Print / Share

The workflow shall remain consistent throughout Furniture GO.

---

# 4. Import Project

Users begin by importing Designer Documents.

Supported document types may include:

- Designer PDF
- DWG Drawings
- Supported Images
- Project Notes
- Site Photos

Furniture GO automatically organizes all imported documents into one Project.

Users are not required to organize documents manually.

---

# 5. Review Recognition Report

After AI Scan is completed, Furniture GO shall generate a Recognition Report for user review.

The Recognition Report may include:

- Successfully Recognized Items
- Missing Information
- Inconsistent Information
- Recognition Warnings
- Suggested User Confirmation

Users shall review the Recognition Report before continuing.

Furniture GO shall never generate production documents before the Recognition Report has been reviewed.

---

# 6. Site Survey

After reviewing the Recognition Report, users may perform a Site Survey.

Typical Site Survey activities may include:

- Verify Actual Dimensions
- Verify Installation Environment
- Record Site Notes
- Record Site Conditions
- Take Site Photos
- Update the Editable Project PDF

The Original Designer Documents shall always remain unchanged.

Only the Editable Project PDF may be modified.

---

# 7. Project Confirmation

After Site Survey and project discussion have been completed, users shall confirm the final engineering information.

Typical confirmation activities may include:

- Confirm Dimensions
- Confirm Materials
- Confirm Hardware
- Confirm Special Requirements
- Confirm Site Changes
- Resolve Recognition Issues

Only confirmed project information shall be used for production generation.

Users remain responsible for every engineering decision.

---

# 8. Generate Production Documents

After Project Confirmation has been completed, users may generate production documents.

Generated documents may include:

- Material List
- Hardware List
- Cutting List
- Manufacturing Requirements
- Shop Drawings
- Quotation
- Project Package

Furniture GO shall automatically generate production documents using the confirmed Project only.

The system shall never generate production documents from unconfirmed project information.

---

# 9. Review Production Results

After production documents have been generated, users may review the results.

Typical review activities may include:

- Review Material List
- Review Hardware List
- Review Cutting List
- Review Shop Drawings
- Review Manufacturing Requirements
- Review Quotation

If modifications are required, users may update the Project and regenerate only the affected production information.

---

# 10. Update Project

If changes are required after Project Confirmation, users may update the Project.

Typical updates may include:

- Dimension Changes
- Material Changes
- Hardware Changes
- Site Condition Changes
- Designer Revisions
- Additional Furniture
- Furniture Removal

Furniture GO shall automatically identify the affected production information.

Only affected production documents shall be regenerated.

Unaffected production information shall remain unchanged.

---

# 11. Export, Print and Share

After production documents have been reviewed, users may:

- Export
- Print
- Share
- Archive

Supported export content may include:

- Project Package
- Material List
- Hardware List
- Cutting List
- Manufacturing Requirements
- Shop Drawings
- Quotation
- Project Reports

Each document may be exported individually or as part of the complete Project Package.

---

# 12. Project History

Furniture GO shall preserve the complete working history of every Project.

Project History may include:

- Imported Designer Documents
- Recognition Reports
- Site Survey Updates
- Project Confirmations
- Project Revisions
- Production Document Generations
- Export History

Historical records shall remain available for future reference.

Previous Project Versions shall never be overwritten.

---

# 13. User Responsibilities

Furniture GO assists users throughout the workflow.

Users remain responsible for:

- Reviewing Recognition Reports
- Performing Site Surveys
- Confirming Engineering Information
- Confirming Production Decisions
- Reviewing Production Documents

Furniture GO shall assist users by automating repetitive work.

Final engineering and production decisions shall always belong to the user.

---

# 14. Workflow Reliability

The User Workflow shall ensure that every Project follows a complete and reliable production preparation process.

Furniture GO shall never:

- Skip Recognition Review
- Skip Project Confirmation
- Generate Production Documents from unconfirmed information
- Overwrite Original Designer Documents
- Remove Project History automatically

If required project information is incomplete, Furniture GO shall notify the user before continuing.

The User Workflow shall always preserve user decisions and project history.

---

# 15. Design Principles

The User Workflow shall follow these principles:

1. User-Centered Workflow
2. AI-Assisted Preparation
3. Recognition Before Confirmation
4. Confirmation Before Production
5. Production Based on Confirmed Information Only
6. Automatic Regeneration of Affected Results
7. Complete Project Traceability
8. No Automatic Engineering Decisions
9. Fully Offline Operation
10. Consistent Workflow Across All Projects

---

# 16. Scope

This PRD defines only the User Workflow.

The following systems are defined separately:

- Project System
- Furniture Intelligence Engine
- Project Recognition and Analysis Engine
- Project Confirmation System
- Furniture Object Engine
- Official Engineering Knowledge Base
- Factory Reference Database System
- AI Recognition Database System
- Production Formula Engine
- Board Generation Engine
- Cutting Optimization Engine
- Manufacturing Requirements Engine
- Furniture Shop Drawing Generation Engine
- Project Document Package Engine

The User Workflow describes only how users interact with Furniture GO.

Internal recognition, engineering, and production processes are handled by their respective systems.
