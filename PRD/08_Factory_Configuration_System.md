# 1. Overview

The Factory Configuration System is responsible for managing factory-specific preferences, operational settings, and default configurations used by Furniture GO.

The Factory Configuration System allows each factory to customize its working environment without modifying the Official Engineering Knowledge Base.

Engineering Rules, Construction Methods, Production Formulas, and Manufacturing Standards shall always originate from the Official Engineering Knowledge Base.

The Factory Configuration System manages only factory-specific configuration.

It shall never define engineering knowledge or production calculation rules.

---

# 2. Objectives

The Factory Configuration System shall:

- Store Factory Information.
- Store Factory Preferences.
- Store Default Project Settings.
- Store Display Preferences.
- Store Printing Preferences.
- Store Label Preferences.
- Store Factory Reference Information.
- Support Factory-specific Configuration.

The Factory Configuration System shall never replace the Official Engineering Knowledge Base.

---

# 3. Factory Setup

Factory Setup shall normally be completed during the initial installation.

Users may modify Factory Configuration at any time through Factory Settings.

Factory Configuration may include:

- Factory Name
- Factory Logo
- Factory Contact Information
- Default Measurement Units
- Default Language
- Default Currency
- Default Time Zone
- Default Project Preferences

Factory Configuration becomes the default environment for future projects.

Project-specific decisions shall never modify Factory Configuration automatically.

---

# 4. Configuration Principles

The Factory Configuration System shall configure how the factory uses Furniture GO.

Factory Configuration may influence:

- User Interface
- Default Options
- Display Preferences
- Printing Preferences
- Project Defaults

Factory Configuration shall never influence:

- Engineering Knowledge
- Engineering Rules
- Construction Methods
- Production Formulas
- Manufacturing Calculations

All engineering standards shall remain under the Official Engineering Knowledge Base.

---

# 5. Factory Preferences

The Factory Configuration System shall store factory-specific preferences.

Factory Preferences may include:

- Preferred Material Brand
- Preferred Hardware Brand
- Preferred Supplier
- Preferred Laminate Brand
- Preferred Board Naming Style
- Preferred Project Number Format
- Preferred Cabinet Naming Style

Factory Preferences shall be used only as default selections.

They shall never replace Engineering Rules or user decisions.

---

# 6. Default Project Settings

The Factory Configuration System shall provide default settings for newly created projects.

Default Project Settings may include:

- Default Board System
- Default Measurement Unit
- Default Currency
- Default Tax Settings
- Default Project Template
- Default Drawing Scale
- Default Annotation Style

Users may modify these settings for individual projects.

Project-specific changes shall not modify the Factory Configuration.

---

# 7. Display Preferences

The Factory Configuration System shall allow factories to customize how information is displayed.

Display Preferences may include:

- Language
- Theme
- Date Format
- Time Format
- Number Format
- Dimension Display
- Default Dashboard Layout
- Default Project View

Display Preferences shall affect only the user interface.

They shall never affect engineering calculations.

---

# 8. Printing Preferences

The Factory Configuration System shall support customizable printing preferences.

Printing Preferences may include:

- Paper Size
- Paper Orientation
- Drawing Scale
- Company Logo
- Company Header
- Company Footer
- Default Print Layout
- Watermark

Printing Preferences shall affect document presentation only.

They shall never modify production data or engineering information.

---

# 9. Label Preferences

The Factory Configuration System shall support factory-specific production label settings.

Label Preferences may include:

- Board Label Layout
- QR Code Display
- Barcode Display
- Cabinet ID Display
- Board Name Display
- Material Display
- Edge Band Information
- Custom Factory Logo

Label Preferences shall affect label appearance only.

They shall never modify Production Boards or Engineering Records.

---

# 10. Factory Reference

The Factory Configuration System shall maintain factory-specific reference information.

Factory Reference information may include:

- Factory Alias
- Factory Product Codes
- Internal Naming Preferences
- Preferred Display Names
- Internal Classification
- Reference Notes

Factory Reference information shall assist users in identifying products within the factory.

Factory Reference information shall never replace Official Engineering Knowledge.

---

# 11. User Preferences

The Factory Configuration System shall support user-specific preferences.

User Preferences may include:

- Default Home Screen
- Default Project Dashboard
- Notification Preferences
- Measurement Display Style
- Theme Preferences
- Toolbar Layout
- Shortcut Preferences

User Preferences shall affect only the user experience.

They shall never modify Factory Configuration or Engineering Rules.

---

# 12. Configuration Validation

The Factory Configuration System shall automatically validate Factory Configuration.

Validation may include:

- Required Factory Information
- Default Project Settings
- Printing Configuration
- Label Configuration
- Display Configuration

If configuration information is incomplete, Furniture GO shall notify the user before the configuration is saved.

The Factory Configuration System shall never generate engineering warnings.

---

# 13. Configuration Backup

The Factory Configuration System shall support backup and restoration of Factory Configuration.

Backup information may include:

- Factory Information
- Factory Preferences
- Default Project Settings
- Display Preferences
- Printing Preferences
- Label Preferences
- User Preferences

Restoring Factory Configuration shall not modify:

- Engineering Records
- Project Data
- Official Engineering Knowledge
- Production History

---

# 14. Configuration Updates

Whenever Factory Configuration is modified, Furniture GO shall apply the updated configuration only to future operations.

Existing confirmed projects shall continue using their confirmed Engineering State unless users choose to regenerate the project.

Factory Configuration updates shall never automatically modify:

- Confirmed Engineering Records
- Furniture Objects
- Production Formula Results
- Production Documents

---

# 15. System Integration

The Factory Configuration System shall integrate with:

- Official Engineering Knowledge Base
- Factory Reference Database System
- Project Confirmation System

The Factory Configuration System may provide default preferences to:

- Project Recognition and Analysis Engine
- Furniture Object Engine
- Project Document Package Engine

The Factory Configuration System shall never provide engineering rules or production formulas.

Engineering knowledge shall always originate from the Official Engineering Knowledge Base.

---

# 16. Configuration Reliability

The Factory Configuration System shall ensure that all configuration information remains valid and consistent.

The system shall never:

- Modify Engineering Knowledge
- Modify Engineering Records
- Modify Furniture Objects
- Modify Production Formula Results
- Modify Confirmed Engineering States

If configuration information is incomplete or invalid, Furniture GO shall notify the user before saving the configuration.

Factory Configuration shall never affect production calculations directly.

---

# 17. Design Principles

The Factory Configuration System shall follow these principles:

1. Factory Configuration Only
2. Factory Preference Driven
3. Default Settings Management
4. User Experience Configuration
5. Printing and Display Configuration
6. Automatic Configuration Validation
7. No Engineering Knowledge Management
8. No Production Calculations
9. Fully Offline Operation
10. Expandable Through Future Configuration Modules

---

# 18. Scope

This PRD defines only the Factory Configuration System.

The following systems are defined separately:

- Official Engineering Knowledge Base
- Factory Reference Database System
- AI Recognition Database System
- Project Recognition and Analysis Engine
- Project Confirmation System
- Furniture Object Engine
- Production Formula Engine
- Board Generation Engine
- Cutting Optimization Engine
- Manufacturing Requirements Engine
- Furniture Shop Drawing Generation Engine
- Project Document Package Engine

The Factory Configuration System is responsible only for factory configuration, factory preferences, default settings, display configuration, printing configuration, and user experience.

Engineering knowledge belongs exclusively to the Official Engineering Knowledge Base.

Factory-specific product references belong exclusively to the Factory Reference Database System.
