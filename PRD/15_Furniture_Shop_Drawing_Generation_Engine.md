# 1. Overview

The Furniture Shop Drawing Generation Engine is responsible for automatically generating production-ready furniture shop drawings from confirmed Furniture Objects and Production Formula results.

The engine converts engineering calculation results into standardized manufacturing drawings suitable for factory production.

The Furniture Shop Drawing Generation Engine does not perform engineering calculations.

It does not create Engineering Rules.

It does not modify Furniture Objects.

Its responsibility is to transform confirmed production information into clear, standardized, editable production drawings.

The generated shop drawings shall never modify the original Designer Drawings.

---

# 2. Objectives

The Furniture Shop Drawing Generation Engine shall:

- Generate furniture shop drawings.
- Generate cabinet elevations.
- Generate cabinet sections.
- Generate cabinet plan views.
- Generate production dimensions.
- Generate construction details.
- Generate processing details.
- Generate editable production drawings.
- Export production drawings.

The engine shall generate drawings only after Engineering Recognition, Project Confirmation and Production Formula calculations have been completed.

---

# 3. Input Requirements

The Furniture Shop Drawing Generation Engine shall begin only after the following workflow has been completed:

Project

↓

AI Recognition Engine

↓

Official Engineering Knowledge Base

↓

Engineering Record

↓

Furniture Object Engine

↓

Project Confirmation

↓

Production Formula Engine

Only confirmed Furniture Objects together with Production Formula results may be used to generate production drawings.

The Shop Drawing Generation Engine shall never perform independent engineering calculations.

---

# 4. Drawing Generation Principles

The Furniture Shop Drawing Generation Engine generates drawings from production information.

Every generated drawing shall originate from:

- Confirmed Furniture Objects
- Official Engineering Knowledge
- Production Formula Results

The Shop Drawing Generation Engine shall never estimate missing information.

If required engineering information is unavailable, the system shall request user confirmation before drawing generation.

The generated drawings shall always represent Final Production Information.

---

# 5. Generated Drawing Types

The Furniture Shop Drawing Generation Engine shall automatically generate standardized production drawings.

Generated drawing types include, but are not limited to:

- Front Elevation
- Rear Elevation
- Left Elevation
- Right Elevation
- Plan View
- Bottom View
- Section View
- Detail View
- Exploded View (where applicable)
- Assembly View
- Board Identification View

Every generated drawing shall be suitable for manufacturing.

---

# 6. Drawing Content

Every generated shop drawing shall be created using:

- Confirmed Furniture Objects
- Engineering Records
- Production Formula Results

A drawing may include:

- Cabinet Name
- Cabinet Number
- Overall Dimensions
- Production Dimensions
- Material Information
- Cabinet Structure
- Door Information
- Drawer Information
- Shelf Information
- Hardware Information
- Manufacturing Requirements
- Processing Information
- Production Notes

All drawing information shall originate from confirmed engineering data.

The Shop Drawing Generation Engine shall never generate unconfirmed production information.

---

# 7. Automatic Drawing Layout

The Furniture Shop Drawing Generation Engine shall automatically organize every production drawing using standardized templates.

Each cabinet drawing shall maintain a consistent layout.

A standard layout may include:

- Front Elevation
- Side Elevation
- Plan View
- Section View
- Detail View

Future drawing templates may be expanded without changing the drawing engine architecture.

---

# 8. Production Dimension Generation

The Shop Drawing Generation Engine shall automatically display all production dimensions generated by the Production Formula Engine.

Examples include:

- Overall Width
- Overall Height
- Overall Depth
- Panel Dimensions
- Door Dimensions
- Drawer Dimensions
- Shelf Dimensions
- Gap Dimensions
- Installation Clearances
- Processing Dimensions

The Shop Drawing Generation Engine shall never calculate dimensions independently.

All displayed dimensions shall originate from Production Formula results.

---

# 9. Production Annotation

The Shop Drawing Generation Engine shall automatically generate standardized production annotations.

Annotations may include:

- Cabinet Name
- Cabinet Number
- Material Code
- Board Thickness
- Edge Banding
- Hardware References
- Processing Information
- Manufacturing Requirements
- Production Notes

Annotation terminology shall remain standardized throughout the entire project.

Annotations shall always reference confirmed engineering information.

---

# 10. Detail Drawing Generation

The Furniture Shop Drawing Generation Engine shall automatically generate production detail drawings whenever required.

Detail drawings provide manufacturing information that cannot be fully represented in standard elevations or sections.

Examples include:

- LED Installation Detail
- Hidden Handle Detail
- Finger Groove Detail
- Fluted Panel Detail
- Glass Installation Detail
- Aluminium Profile Detail
- Corner Construction Detail
- Joint Detail
- Assembly Detail

Every detail drawing shall originate from confirmed Furniture Objects and Production Formula results.

The Shop Drawing Generation Engine shall never generate engineering details independently.

If required engineering information is unavailable, user confirmation shall be requested before detail drawing generation.

---

# 11. Production Processing Information

The Shop Drawing Generation Engine shall automatically display production processing information.

Processing information may include:

- Hole Positions
- Hole Diameters
- Hole Depths
- Groove Positions
- Groove Width
- Groove Depth
- Rebate Positions
- Edge Banding Locations
- Processing Directions
- CNC Processing Information (Future)

All processing information shall originate from the Production Formula Engine.

The Shop Drawing Generation Engine shall never calculate processing information independently.

---

# 12. Drawing Standards

All generated production drawings shall follow one unified drawing standard.

The standard shall define:

- Text Style
- Dimension Style
- Line Weight
- Layer Naming
- Symbols
- Drawing Scale
- Annotation Style
- Leader Style

Every drawing inside the same project shall follow identical drawing standards.

Furniture GO shall never mix multiple drawing standards within one project.

---

# 13. Drawing Revision Management

Furniture GO shall preserve every generated drawing revision.

Example:

Project

├── Shop Drawing Rev 1

├── Shop Drawing Rev 2

├── Shop Drawing Rev 3 (Current)

Rules:

- Previous revisions shall never be overwritten.
- Every revision shall remain available.
- The latest confirmed revision becomes the Current Revision.
- Superseded revisions shall remain identifiable.

Whenever Furniture Objects or Production Formula results change, the Shop Drawing Generation Engine shall generate a new drawing revision automatically.

---

# 14. Export Formats

Furniture GO shall support exporting generated production drawings into multiple formats.

Supported formats include:

- DWG
- DXF
- PDF

Future formats may be introduced without changing the drawing engine architecture.

Every exported drawing shall preserve:

- Drawing Layout
- Production Dimensions
- Processing Information
- Annotations
- Layers
- Symbols
- Production Notes

Editable formats shall remain editable after export whenever supported by the selected file format.

---

# 15. Project Drawing Package

The Furniture Shop Drawing Generation Engine shall automatically organize all generated production drawings into a standardized Project Drawing Package.

A Project Drawing Package may include:

Project

├── Floor

│   ├── Room

│   │   ├── Cabinet

│   │   │   ├── Shop Drawing

│   │   │   ├── Detail Drawing

│   │   │   ├── Section Drawing

│   │   │   └── Assembly Drawing

The Project Drawing Package shall support exporting:

- Individual Cabinet Drawings
- Individual Room Drawing Packages
- Complete Project Drawing Packages

The Project Drawing Package shall remain synchronized with the confirmed Furniture Objects.

---

# 16. Drawing Synchronization

The Furniture Shop Drawing Generation Engine shall remain synchronized with:

- Official Engineering Knowledge Base
- Furniture Object Engine
- Production Formula Engine

Whenever confirmed Furniture Objects or Production Formula results change, all affected drawings shall be regenerated automatically.

Only affected drawings shall be regenerated.

Unaffected drawings shall remain unchanged.

The Shop Drawing Generation Engine shall never perform independent engineering calculations during synchronization.

---

# 17. Drawing Reliability

The Furniture Shop Drawing Generation Engine shall generate production drawings only from confirmed engineering information.

The engine shall never:

- Guess Dimensions
- Guess Hardware
- Guess Processing Information
- Guess Cabinet Structures
- Guess Engineering Rules

If required engineering information is incomplete, the drawing generation process shall pause and request user confirmation.

Production drawings shall always represent verified manufacturing information.

---

# 18. Design Principles

The Furniture Shop Drawing Generation Engine shall follow these principles:

1. Engineering Knowledge Driven
2. Furniture Object Driven
3. Production Formula Driven
4. Production Oriented
5. Standardized Drawing Layout
6. Automatic Drawing Generation
7. No Independent Engineering Calculations
8. No Estimated Production Information
9. Fully Editable Drawing Output
10. Fully Offline Operation

---

# 19. Scope

This PRD defines only the Furniture Shop Drawing Generation Engine.

The following systems are defined separately:

- Official Engineering Knowledge Base
- AI Recognition Engine
- Factory Reference Database System
- Furniture Object Engine
- Production Formula Engine
- CAD Generation System
- Furniture 3D System
- Cutting Generation System
- Purchase Generation System

The Furniture Shop Drawing Generation Engine is responsible only for transforming confirmed production information into standardized manufacturing drawings.

Engineering calculations belong exclusively to the Production Formula Engine.

Engineering knowledge belongs exclusively to the Official Engineering Knowledge Base.
